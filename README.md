# The Innovative Hunt — 3D Portfolio

A responsive, cinematic portfolio site built with plain HTML, CSS, and JavaScript. No build step is required.

## Preview

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Customize before publishing

1. Replace the sample projects and descriptions in `index.html`.
2. Change `your@email.com` in the contact section.
3. Replace the `#` social links with your profiles.
4. Update the copyright year and page metadata if needed.
5. Colors are controlled by variables at the top of `styles.css`.

## Features

- Interactive canvas-rendered 3D particle globe
- Pointer-driven project card depth effects
- Magnetic buttons and custom cursor
- Scroll-triggered transitions
- Responsive desktop, tablet, and mobile layouts
- Reduced-motion accessibility support
- No framework or package dependencies
